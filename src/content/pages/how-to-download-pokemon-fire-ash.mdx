Pokemon Fire Ash is a fan-made RPG Maker XP game that follows Ash Ketchum’s journey through all nine regions, from Kanto to Galar, including the Orange Islands and Battle Frontier. The latest version, **3.6 Part 2.1**, updated in October 2025, includes over 900 Pokémon, 50+ gyms, Mega Evolution, Z-Moves, Dynamax, and much more. This guide covers everything you need to download and play the game on Windows PC or Android using JoiPlay. For a full overview of the game’s story and features, visit the **[home page](/)**.

## Step 1: Download the Game

The game is distributed as a compressed archive. Choose one of these mirrors:

- **Mediafire** – [Download link](https://www.mediafire.com/…) (from the source)
- **Mega** – [Download link](https://mega.nz/…) (requires Mega app for large files)

The file size is roughly 1–2 GB compressed. If you use Mega and get a “download is too big” message, install the Mega app or use the Mediafire link instead.

<Callout type="info" title="Version Note">
  The original download page also provides previous versions if you need an older release, but the latest (v3.6 Part 2.1) is recommended for bug fixes and new features.
</Callout>

## Step 2: Extract the Files

Once the archive is downloaded, extract it using a tool like **7-Zip** (free) or **WinRAR**. Right‑click the file and choose “Extract here” or “Extract to [folder name]”. After extraction, you’ll see a folder containing the game executable (`Game.exe`) and supporting files.

## Step 3: Install RPG Maker RTP (Required for PC)

Pokemon Fire Ash runs on **RPG Maker XP** and needs the **RPG Maker XP RTP** (Run‑Time Package) to work. If you haven’t installed it before, download and install the RTP from the official RPG Maker site. This is a one‑time install that enables all RPG Maker XP games to run.

## Step 5: Play on Android with JoiPlay

Pokemon Fire Ash is an RPG Maker XP game, not a GBA ROM, so you cannot run it on a standard GBA emulator. Instead, use **JoiPlay**, an Android app that supports RPG Maker games.

### Install JoiPlay and the RPG Maker Plugin

- **JoiPlay** – [Download from Mega](https://mega.nz/file/XvJhgTzB#snL1VhDbHP67I0EkfJMgGNF-2qJbxwtPND2M9uybbT8) (or from the Play Store if available)
- **RPG Maker Plugin** – [Download from Mega](https://mega.nz/file/m7hSgY5C#dEpiPModrrMg3Lpfo3xrGxciJlc8Wp_mHyTV-6H_Dmo)

Install both APKs on your Android device. If you can’t find JoiPlay on the Play Store, use the Mega link.
