Patching sounds scarier than it is. A patch file is a small set of
instructions that turns a clean ROM into the hacked game. You bring the ROM,
the patch brings the changes, the patcher glues them together. None of the
steps need an account, and nothing here installs anything secretly.

<Callout type="warn" title="Match the base ROM">
  A hack built on FireRed will not patch onto Emerald. The patcher will run and
  produce a file that black-screens. Read which base the release page asks for
  before you start.
</Callout>

<Callout type="tip" title="Keep the clean ROM">
  Keep your clean ROM around. If a hack updates, you patch onto the clean copy
  again. Patching onto an already-patched ROM corrupts it.
</Callout>

<Quote author="A longtime ROM hack maintainer" source="release notes">
  Ninety percent of the bug reports I get are people who patched onto the
  wrong base, or onto a ROM they already patched. Start clean, every time.
</Quote>
