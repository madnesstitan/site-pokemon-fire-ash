## Installing on PC

Pokemon Fire Ash is an RPG Maker XP game, not a GBA ROM. You do not need an emulator.

<Steps items={[
  "Download the full game archive (either Mega or Google Drive link).",
  "Extract the ZIP or RAR file to a folder on your computer (e.g., `C:\\Games\\Pokemon Fire Ash`).",
  "Open the folder and double-click `Game.exe`.",
  "The game launches immediately. No additional setup is required."
]} />

If you downloaded the version without audio, extract the audio pack into the same folder. The game will then play music and sound effects.

<Callout type="tip" title="Save File Permissions">
  Keep the game folder in a location with write permissions (not inside Program Files) so save files work correctly.
</Callout>

## Installing on Android

The game is not a native Android app. You need **Joiplay**, a free app that runs RPG Maker games on Android.

<Steps items={[
  "Download and install [Joiplay](https://joiplay.cyou/) from its official site or the Play Store.",
  "Install the **RPG Maker Plugin** for Joiplay (also available from the same source).",
  "On your PC, extract the game folder (the one containing `Game.exe`).",
  "Transfer the entire game folder to your Android device (via USB, cloud, or SD card).",
  "Open Joiplay, tap the **+** button, and select the game folder.",
  "Choose `Game.exe` as the executable. Joiplay will detect the RPG Maker engine.",
  "Tap the game icon to launch."
]} />

You may need to adjust the graphics settings in Joiplay if the game runs slowly. Lowering the resolution or disabling certain effects can help on older phones.
